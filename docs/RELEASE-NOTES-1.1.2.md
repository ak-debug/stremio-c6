# Stremio AK 1.1.2

Adds a **Stats** button beside the existing player controls. Press OK to show controls, select Stats to open the panel, and press Back or Stats again to close it. The optional remote Info key remains supported.

The panel stops polling when closed and does not intentionally change the selected source, playback position, pause state, or backend. A device test opened and closed it during advancing 3840×2160 playback with those states preserved.

See [device validation](DEVICE-VALIDATION.md) for HDR observations and limits, and [release status](RELEASE-READINESS.md).
